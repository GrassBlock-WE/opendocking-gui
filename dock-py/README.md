# Open Docking (Python package)

Python front-end for the [Open Docking](https://github.com/GrassBlock-WE/opendocking-gui) engine.
molecular docking engine.

    pip install odockmcode
    odockmcode info
    odockmcode dock -r receptor.pdbqt -l ligand.pdbqt \
        --center_x 0 --center_y 0 --center_z 0 \
        --size_x 22 --size_y 22 --size_z 22 -o poses.pdbqt

See the repository README for the full documentation.
